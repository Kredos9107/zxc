## 2.4 Фазовая плоскость
Генератор 150 Гц, 100 мкс. Вертикальные курсоры a и b стоят на соседних витках (n = 1). Таблица курсоров на экране в режиме X–Y не обновляется, поэтому положения сняты по сетке (см. чистовик, табл. 3).
R = 0,41 / 0,36 / 0,30 / 0,26 / 0,20 кОм → фото 0107 / 0109 / 0110 / 0111 / 0112, в порядке съёмки. Декремент по курсорам монотонно падает с R, так что порядок правильный.
