## Итог

± — стандартная неопределённость (k = 1). Cu, Ag — электроны, Zn — дырки.

## Принятые решения (что где спорно)

- Цена деления холловских серий 0,04 мкВ/дел (предел 3 мкВ). Подтверждается тем, что R_H Cu и Ag получаются близкими к табличным.
- Поле — интерполяция по прямому ходу калибровки (серии снимались при росте поля). «+831 мТл» при 0,75 А — потерянный минус.
- U₀: для Cu и Zn — отсчёт при Iм = 0 внутри серии (в шапках записано «1», это не совпадает с отсчётом без поля); для Ag — записанный U₀. На наклоны U₀ не влияет (МНК со свободным членом).
- Медь: серии 0,20 и 0,40 А сняты при K₂ = 2 → умножены на −1.
- Исключены две записи меди: I = 0,40 А, Iм = 1,00 А «0» (пустая клетка) и I = 1,07 А, Iм = 0,90 А «23» (описка; соседи 35 и 38, в обратной серии 38).
- Обратное поле: показания тоже растут — по п. 8 доп. описания K₂ всегда ставят так, чтобы стрелка шла вправо; сравнение по модулю.
- Знак носителей — сравнением Zn с Cu при K₁ = 1, K₂ = 1 (абсолютная полярность проводов не записана). Для Ag положение K₂ не записано.
- k(I): основной вариант — МНК со свободным членом; через ноль (проверка) для Ag даёт R_H = 0,88·10⁻¹⁰ (почти табличное).
- В п. 19 лабника «константа Холла цинка отрицательна» — по-видимому опечатка (во введении Zn — дырочный металл, опыт это подтверждает).
- Размеры: Δh = 0,005 мм, Δa = Δl = 0,5 мм (последняя цифра на держателе). Для Zn продольное напряжение не мерили → ρ, μ цинка нет.
