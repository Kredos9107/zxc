# ПЦП — «Водяной вихрь»

- `Vortex_v8_доработка/` — актуальная плата KiCad, схема, посадочные места и результаты проверки. Открывать `Vortex_v8_доработка.kicad_pro`.
- `led_test.ino` — сохранённая прошивка управления насосом и подсветкой.
- `encoder_test/` — тест энкодера.
- `encoder_test_backup/` — резервная копия прошивки ESP32 до теста энкодера; нужна для восстановления.
- `состояние.md`, `корпус.md` — описание проекта и корпуса. Состояние записано 28.10.2026; сведения о плате v8 от 01.11.2026 находятся в её `ПРОЧИТАЙ.txt`.
- `PROJECT-CONTEXT.md`, `AGENTS.md`, `instructions-original.txt` — контекст и инструкции.
- `Старые_версии_и_разработка.zip` — версии платы v2–v7, пробные разводки, исходные скрипты, промежуточные платы v8 и служебные данные экспорта. Для запуска старых скриптов распаковать архив в отдельную папку с сохранением структуры.

При уборке 02.11.2026 старые наработки перенесены в архив с проверкой контрольных сумм. Точные копии материалов из `materials/` удалены; основные экземпляры находятся в корне.
