# Финальная прошивка «Водяной вихрь»

Исходник: `Vortex_final/Vortex_final.ino` — весь код в одном файле.

Для Arduino IDE подготовлен один самостоятельный скетч: `Arduino_IDE/Vortex_final/Vortex_final.ino`. Открыть его и выбрать ESP32 Dev Module. Требуется библиотека FastLED; WebServer/WiFi/ESPmDNS входят в ядро ESP32. ESPAsyncWebServer и AsyncTCP этой версии не нужны.

- Насос: GPIO25, ШИМ 20 кГц, диапазон 148–255, плавный разгон. После перезапуска всегда выключен.
- Лента: GPIO23, WS2811, BRG, 20 адресуемых пикселей. Количество и порядок цветов сохранены из предыдущего скетча; после обрезки ленты число нужно уточнить.
- Энкодер насоса: CLK 4, DT 16, SW 17. Вращение: скорость по 2%; нажатие: вкл/выкл.
- Энкодер света: CLK 18, DT 19, SW 21. Вращение: яркость по 5/255 или оттенок по 4/256. Нажатие переключает регулировку яркости и цвета. При запуске выбрана яркость.
- Эффекты выбираются с сайта: один цвет, радуга, цвет по скорости, бегущий огонь. Ручной оттенок действует для одного цвета и бегущего огня.
- Сайт опрашивает состояние каждые 0,5 с, отправляет только изменённые параметры.
- Домашний Wi-Fi использует настройки, уже сохранённые в NVS ESP32. Пароля в исходниках нет. При отсутствии подключения через 10 с появляется сеть `Vortex`, пароль `12345678`, адрес `http://192.168.4.1`. Подключение к домашней сети продолжает восстанавливаться.
- Адрес в домашней сети печатается в Serial (115200); также предусмотрен `http://vortex.local`.

Проверенная плата при подготовке: ESP32-D0WD-V3, 4 МБ, CH340, COM6. Ядро ESP32 3.3.12, FastLED 3.10.7. Порт нужно проверять перед каждой следующей прошивкой.

Сборка из корня проекта в PowerShell:

```powershell
& 'C:\Users\Данил\AppData\Local\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe' --config-file '.\firmware\arduino-cli.yaml' compile --jobs 2 --fqbn esp32:esp32:esp32 --build-path '.\firmware\build' --output-dir '.\firmware\release' '.\firmware\Vortex_final'
```

Полная резервная копия до замены прошивки: `backup_2026-11-11/before_final.bin` (4 МБ, включая настройки Wi-Fi). Хранить локально.

Перед USB отключить питание от XL4015 / снять JP1. Насос включать только в воде. Питание энкодеров — 3V3.
